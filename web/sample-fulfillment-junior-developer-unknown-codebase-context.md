## 파일럿 약속 범위
- 목표: 이슈와 레포를 읽고 수정 후보 파일, 영향 범위, 검증 명령을 묶어준다
- 납품물: 수정 영향도 맵 + 테스트 초안 + PR 설명문
- 처리 방식: 운영자가 자료를 읽고 컨시어지 방식으로 1차 결과물을 만든다.
- 기본 납기: 영업일 3일. 자료가 부족하면 확인 질문을 먼저 보낸다.
