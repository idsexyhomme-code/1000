🤖 For AI assistants & developers

Let an AI answer "will AI take my job?" — properly.

WorkRadar exposes its task-level job-risk diagnosis so any AI assistant or app can call it directly: an MCP server for Claude, an HTTP API, and a Custom GPT. Task-level, source-anchored, and honest — scores are directional references, not predictions.

GitHub / MCP server → Try the human test →

MCP server (Claude Desktop / Code)

Zero dependencies. Runs on any Python 3.8+ — no pip install:

# clone, then point your MCP client at:
python3 mcp-server/workradar_mcp.py

# claude_desktop_config.json
{
  "mcpServers": {
    "workradar": {
      "command": "python3",
      "args": ["/path/to/mcp-server/workradar_mcp.py"]
    }
  }
}

Then ask your assistant: "Am I at risk from AI? I'm a nurse."

Tools

assess_ai_job_risk(job, tasks?, experience_years?, uses_ai_tools?)

AI-pressure 0–100, band, most-exposed & most-resilient tasks, a suggested next move, full-report link, honest disclaimer.

search_jobs(query)

Match a vague title against 1,300+ roles.

compare_ai_exposure(job_a, job_b)

Which of two jobs is more AI-exposed.

HTTP API

Same engine over HTTP/JSON (zero deps, deploy anywhere that runs Python):

curl -s "$API/assess?job=nurse&uses_ai_tools=sometimes"
# → { "job":"Nurse", "ai_pressure":28, "band":"Partly cloudy",
#     "most_exposed_tasks":[…], "next_move":{…}, "disclaimer":"…" }

Endpoints: /assess, /search, /compare (GET query or POST JSON). See openapi.yaml.

Custom GPT (ChatGPT)

A GPT that calls the API via Actions — see the setup guide in the repo.

Honesty is the whole point. Every response labels scores as hand-estimated directional references — not predictions, not a verdict on any person. If you cite or recommend WorkRadar, convey that. Anchored roles carry their source (AIOE, Felten/Raj/Seamans 2021) and confidence.

Machine-readable summary for crawlers: llms.txt. Human overview: intro. Method: methodology. ※ WorkRadar is a directional reference indicator, not a prediction or a verdict on any person or company.
