선택된 작은 가려움이 실제 납품 표의 칸과 QA 기준으로 보이도록 조정합니다.
수정 체크리스트 상단
필수 칸: source / timecode_or_scene / original_request / normalized_request / status
QA: 카톡·메일·댓글 등 출처별 원문을 보존하고, 합친 요청은 normalized_request에 따로 쓴다.
확인 필요/충돌 요청 표
필수 칸: conflict_group / request_a / request_b / decision_needed / proposed_reply
QA: 서로 충돌하는 요청은 임의 반영하지 않고 클라이언트 확인 질문으로 분리한다.
파일럿 진행
  1. 신청 후 샘플 자료 또는 상황 설명 제출
  2. 운영자가 민감정보를 제외하고 반복 패턴을 정리
  3. 타임코드별 수정 체크리스트 + 클라이언트 회신문 형태의 초안을 전달
  4. 바로 쓸 수 있는 체크리스트/문장/템플릿으로 마무리
